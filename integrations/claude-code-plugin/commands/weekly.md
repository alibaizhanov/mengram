---
description: Weekly memory report — facts learned, procedures, repeated mistakes prevented
---

Run the shell command `mengram weekly` and show its full output to the user verbatim inside a code block (it is a pre-formatted box — do not reflow, summarize, or annotate it).

If the user asks to share it, run `mengram weekly --share` instead — it also prints a ready-to-post summary and copies it to the clipboard.

If the `mengram` command is not found, tell the user to run: `pip install --upgrade mengram-ai` (the weekly report needs mengram-ai >= 2.29.0).
